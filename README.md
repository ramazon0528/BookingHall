BookingHall

BookingHall - REST API для бронирования залов и доступных услуг.

Проект позволяет управлять залами и бронированиями этих залов, а также автоматически расчитывать стоимость брони зала вместе с услугами с учетом продолжительности бронирования и скидок/наценок.

- МОДЕЛИ

Hall - представляет объект зала
HallItem - Используется для связи зала с доступными для зала услугами.
Booking - представляет объект бронирования
BookingItem - промежуточная связь между услугами и бронированиями. Представляет услугу, которую выбрал клиент.
Service - представляет объект услуги.

- ПОИСК ЗАЛА

Поиск реализован с помощью фильтрации специального объекта HallFilter. Он содержит свойста для указания начала времени бронирования, продолжительность брони и вместимость зала. 

Эти данные указываются в качетсве параметров запроса, поэтому параметр метода GetHallsAsync отмечен атрибутом [FromQuery].

Пример URL:

/api/hall?StartTime=2026-10-15T18:00:00&Duration=02:00:00


- БРОНИРОВАНИЕ ЗАЛА

Для создания бронирования клиент передаёт:

ID зала
дату и время начала
продолжительность
выбранные услуги

Пример запроса:

POST /api/booking
Content-Type: application/json

{
    "hallId": 1,
    "bookingStart": "2026-10-02T12:00:00",
    "duration": "02:00:00",
    "bookingItems": [
        {
            "serviceId": 1
        }
    ]
}


- РАСЧЕТ ЦЕНЫ БРОНИРОВАНИЯ

Стоимость бронирования состоит из:

Стоимость зала + Стоимость дополнительных услуг = Общая стоимость

Стоимость зала рассчитывается на основе цены за час и продолжительности бронирования.
Также предусмотрена система скидок и наценок в зависимости от времени начала бронирования.

Текущие тарифы:

Время начала	Изменение
06:00 – 09:00	-10%
12:00 – 14:00	+15%
18:00 – 23:00	-20%
Остальное время	0%


В Качестве Базы данных используется SQLite
